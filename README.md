# TP Git Python

## Présentation
Ce projet a pour objectif de découvrir et de pratiquer les commandes Git et GitHub à travers des exercices en Python.

## Objectifs
- Comprendre le fonctionnement de Git.
- Créer et gérer un dépôt Git.
- Utiliser les commits pour sauvegarder les modifications.
- Synchroniser le projet avec GitHub.

## Outils utilisés
- Python
- Git Bash
- GitHub

## Commandes Git utilisées
- git init
- git add
- git commit
- git status
- git log
- git push
- git pull

## Conclusion
Ce TP m'a permis de découvrir les bases de Git et GitHub et de comprendre comment gérer un projet.
